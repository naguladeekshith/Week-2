# Week-2
This report presents a systematic approach to data cleaning and transformation using Python, focusing on the preparation of raw datasets for reliable data analysis and machine learning. It explains why data quality is important and how missing values, duplicate records, inconsistent formats, invalid data points, and outliers can affect analytical results.

The report describes the use of Pandas for data manipulation, NumPy for numerical operations, and scikit-learn for preprocessing and feature transformation. It outlines procedures for inspecting datasets, standardizing column names, correcting data types, identifying duplicate records, measuring missing values, and selecting appropriate imputation strategies. It also explains how to investigate outliers using statistical methods such as the interquartile range (IQR), while emphasizing that unusual observations should not be removed without proper justification.

The transformation section discusses standardization, min-max scaling, categorical encoding, and feature engineering. It explains how these techniques can improve the suitability of data for different analytical and machine-learning algorithms. The report also highlights common challenges, including data leakage, inappropriate imputation, incorrect assumptions about extreme values, and inconsistent measurement units, along with practical methods to prevent them.

A step-by-step workflow and Python pseudocode are included to demonstrate how the proposed cleaning process can be organized and documented. Finally, the report recommends validation checks, before-and-after comparisons, reproducible processing, and proper documentation of cleaning decisions.

This assignment helped develop a structured understanding of data preparation, the role of Python libraries in data wrangling, and the importance of preserving data integrity throughout the data science workflow.
